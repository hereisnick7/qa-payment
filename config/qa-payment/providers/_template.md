# <Provider> — карточка провайдера

Создаётся/обновляется после каждого прогона (P5 скилла, только после «да»).

## Интеграция
- Код в бэке: <пакет провайдера>, сервисы депозита/вывода.
- Конфиг: <файл> → блок `<provider>` (какие ключи).
- Депозит: методы, коды методов провайдера, тип (H2H / H2F / redirect).
- Вывод: методы, реквизиты и их валидация.
- Ответ провайдера на создание: HTTP-код + статус в теле (депозит / выплата).

## Вебхуки
- Эндпоинты, авторизация.
- Подпись: алгоритм, из чего строится сообщение, заголовки, каким ключом проверяем.
- Тело хука: поля депозита / вывода.
- Статусы провайдера → наши переходы.
- Коды ошибок (битая подпись, противоположный финальный статус, не найдено).

## Особенности стенда / провайдера
- Песочница есть/нет, реквизиты на DEV, таймауты, ретраи хуков.

## Прод (релизная проверка, P6)
- Ретраи хуков по статусам, антифрод на тестовых платежах, маркеры в логах.
